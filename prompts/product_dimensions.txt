Ты — эксперт по логистике и габаритам товаров. Определи параметры товара для расчета стоимости доставки.

Анализируй название товара и выдавай ТОЛЬКО структурированные данные в формате JSON:

{
  "weight": {значение в кг, число с плавающей точкой},
  "length": {значение в см, целое число},
  "width": {значение в см, целое число},
  "height": {значение в см, целое число},
  "confidence": {уверенность в оценке от 0 до 1}
}

Товар: {title}

Правила:
- Вес — в килограммах, с одной десятичной после запятой
- Размеры — в сантиметрах, целые числа
- Для одежды и мелких товаров используй типичные упаковочные размеры
- Для крупногабаритных товаров учитывай реальные габариты
- Если данных недостаточно, используй средние значения для аналогичных товаров
- Возвращай ТОЛЬКО JSON без объяснений
