## Интеграция сервиса доставки от СДЕКК

В данной части мы будем сосдавать отделный сервис который будет взаимодействовать со СДЕКК по API.

Ссылка на документацию https://apidoc.cdek.ru/#tag/auth

### Этап 1

Создай конфиг и добавь в него следующие параметры:

- Адрес среды
- Логин
- Пароль

Так же создай соответсвующие файлы в .env

Организуй отдельный файл сервиса в котором реализуй метод получения токена авторизации. Так же реплизуй метод получения списка населенных пунктов ( документация https://apidoc.cdek.ru/#tag/location/operation/cities)

Так же сделай артисан команду которая будет вызывать метод получения списка населенных пунктов и выводить в консоль. (для отладки)

### Этап 2

В компоненте resources/js/components/cart/Cart.vue есть блок с классом bascet\_\_ в нем 2 колонки нужно сделать так чтобы они были выстроенны в столбик.

### Этап 3

Создай компонент vue (внутри можно разбить на вложенные компоненты) который буду реализовывать интерфейс расчета стоимости дставки.

Данный компонет будет выводиться компоненте @resources/js/components/cart/CartOrderSummary.vue после поля комментария. Этот компонент результатом своей работы будет отдавать тип доставки и данные по ней.

Интерфейс компонета:

Компонет выводит на экран 3 плашки которые моджно выбирать:

- Самовывоз
- Доставка в пункт выдачи
- Доставка курьером

Интерфейс реализуй опираясь на скриншет @public/tmp/2026-08-01_14-30-59.png

Реализуй сначала интерфейс а делее будем работать над функционалом.

## Компонент для выбора пункта выдачи

Компонент будет вызываться при нажатии на кнопку пункт выдачи.
Компонет представляет собой модальное окно. Структура окна следующая:

Шапка в ней заголовок с текстом - Выбор пункта выдачи (левая сторона), крестик для закрытия (правая сторона). Ниже в шапке идет блок с селектом для выбора города этот блок занимает всю ширину окна (по умолчанию выбран Курск)  
Под шапкой распологается блок с картой на которой будут отображаться пины по каждому из пунктов выдачи.

Пока сделай интерфейс и методы для получения списка городов и списка пунктов выдачи. Вызовы API вызовы API для них пропишем потом.

В компоненте @resources/js/components/cart/DeliveryPointModal.vue нужно в момент загрузки получать данные о городах по эндпоинту cdek_cities

Эти города должны выводится в выпадающий список и при смене города карта должна менять свой центр и вызывать метод загрузки пунктов выдачи.

Реализуй следующий механизм для компонета выбора пункта выдачи:
При клике появляется бабл в котором выводится следующая информация:

- Адрес location.address_full
- Комментарий если есть address_comment
- Время работы work_time
- Телефон phones.number

Ниже кнопка с текстом выбрать нажимая на которую и происходит выбор

### Сборка API

У нас уже есть отдельный сервис для работы с API сдека, давай на его основе соберем отдельное API эндпоинты которого защещены сsrf токеном.

Сделай эндпоинт который будет аозвращать список городов на основе метода getCities описанного в сервисе @app/Services/CdekService.php

Так же разработай метод который будет запрашивать список пунктов выдачи по городу ссылка на документацию https://apidoc.cdek.ru/#tag/delivery_point/operation/search. Для него так же создай отдельный эндпоинт

Для эндпоинта cdek_cities нужно сметчить по имени файла с моделью @app/Models/City.php Чтобы в результат попадали координаты из модели City.
