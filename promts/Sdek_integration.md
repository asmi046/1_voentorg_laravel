## Компонент для выбора пункта выдачи

Компонент будет вызываться при нажатии на кнопку пункт выдачи.
Компонет представляет собой модальное окно. Структура окна следующая:

Шапка в ней заголовок с текстом - Выбор пункта выдачи (левая сторона), крестик для закрытия (правая сторона). Ниже в шапке идет блок с селектом для выбора города этот блок занимает всю ширину окна (по умолчанию выбран Курск)  
Под шапкой распологается блок с картой на которой будут отображаться пины по каждому из пунктов выдачи.

Пока сделай интерфейс и методы для получения списка городов и списка пунктов выдачи. Вызовы API вызовы API для них пропишем потом.

В компоненте @resources/js/components/cart/DeliveryPointModal.vue нужно в момент загрузки получать данные о городах по эндпоинту cdek_cities

Эти города должны выводится в выпадающий список и при смене города карта должна менять свой центр и вызывать метод загрузки пунктов выдачи.

Реализуй следующий механизм для компонета выбора пункта выдачи:
При клике появляется бабл в котором выводится следующая информация:

- Адрес location.address_full

- Время работы work_time
- Телефон phones.number

В проекте реализованна комманда для рассчета стоимости доставки по тарифам @app/Console/Commands/CdekAvailableTariffs.php Она работает на основе сервиса @app/Services/CdekService.php. Так же в проекте есть API эндпоинты которого прописаны в @routes/asmi_cdek.php

Твоя задача сделать в вервисе CdekService отдельный метод который будет принимать информацию о весе товаров в корзине, код города в который необходимо доставить товар и производить расчет аналогично комманде CdekAvailableTariffs вызывая метод СДЕК API /calculator/tarifflist. Для этого метода нужно сделать отдельный эндпоинт в API.

Пример вызова команды из консоли:

```bash
php84 artisan cdek:available-tariffs --from_code=699 --to_code=141 --weight=2 --json
```

Обрати внимание что from_code всегда = 699 так как отправка всегла досуществляется из этого города.

После вызова метода СДЕК API /calculator/tarifflist в ответе придет структура как в файле @podb_tarif.json. В качестве релевантного ответа тебе нужно выбрать элемент с "delivery_mode": 4, и минимальной ценой описанной в поле "delivery_sum".

Реализованный в рамках задания эндпоинт нужно вызвать в методе заглушке calculateDeliveryPriceStub созданном ранее. В выбранном элементе будет блок с датами доставки:

```json
"delivery_date_range": {
                "min": "2026-08-10",
                "max": "2026-08-11"
            }

```

Эти даты доставки нужно вывести в span с классом .delivery_option\_\_desc отдельной строкой.
