Необходимо написать artisan комманду которая возьмет данные по каждому товару из таблицы `products` и при помощи запроса по API к модели AI определит вес, ширину высоту и длиннй.

Определение данных параметров производится с целью обеспечения возможности расчета стоимости доставки данного товара.

В рамках выполнения данной задачи составь промт для взвешивания в котором будет фигурировать title товара из таблицы. в промте проси AI выдавать структурированные данные. Результаты определения сохрани в отдельный json файл, идентификатором товара пусть будет поле sku.

Доступ к моделям будет промзводится через сервер ollama. Сделай отдельный конфиг для настройки подключения к этому сервису.
