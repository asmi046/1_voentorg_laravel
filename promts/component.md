В компоненте @resources/js/components/cart/PageToCart.vue реалезован селект в виде простого выпадающего списка:

```vue
<select v-show="prices.length > 1" v-model="selected" name="prices">
                <option
                    v-for="(item, index) in prices"
                    :key="item.id"
                    :value="item.sku"
                >
                    {{ item.value }}
                </option>
            </select>
```

При помощи данного селекта выбирется вариация товара.

Вынеси эту логику в отдельный компонент и реализуй в виде костомного компонента для выбора. Визуально это должно выглядеть следующим образом:
набор кнопок с отступами между ними активная кнопка подсвечена.

В компонент должен передаваться sku. Если такой sku есть в списке, то его сделать подсвеченным по умолчанию, если нет, то первый элемент в списке подсвечивается по умолчанию.

Стили для компонента размести в файл @public/scss/cart/\_to_cart_widget.scss
