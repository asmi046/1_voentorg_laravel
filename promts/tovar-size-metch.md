Исходные данные:
Есть сайт в базе которого есть товары, каждый может иметь ряд модификаций (размер, цвет и т.д.). Есть файл выгрузки из системы учета в котором хранятся названия товаров числовые значения штрихкодов и идентификаторы. Названия в базе сайта в выгрузке не совпадают, в файле выгрузке модифицирующий параметр прописан в названии товара, например:

Платье форменное Полиция летнее с длинным рукавом (габардин) (А) р-р.48/164

48/164 - нужный модификатор

Задача:
Необходимо сопоставить товары из выгрузки с товарами в базе сайта.

Предложи варианты решения и инструменты для решения задачи.

---

На основе имеющихся наработок, создай отдельный скрипт на базе которого я буду эксперементировать и постепенно его развивать улучшая результат слияния.

В начале давай создадим временную таблицу в которую спарсим все данные из файла import0_1.xml в формате:

- Наименование
- Размер
- Штрихкод
- Ид

Перед началом выполнения очищай временную таблицу.

Поле штрихкод сделай уникальным, если будет ошибка дублирования при добавлении записывай данные в отдельный json файл. При повторном выполнении скрипта его тоже очищай.

На основе имеющихся наработок выдели размеры из названия, если не выделяются то пиши в поле Наименование параметр из файла как есть.

В консоли выведи колличество добавленных записей в итоговую таблицу. Показывай прогресс выполнения скрипта в процентах.

---

Давай добавим при помощи миграции в таблицу `product_prices` следующие поля:

- ext_id - Ид из 1С
- category_id - UUID категории 1С
- count - количество товара на складе

---

Теперь вернемся к доработке скрипта import:parse-offers. После создания таблицы добавь следующий функционал:

Очищай таблицу product_prices.

Запусти цикл по всем записям таблицы products, в цикле проверяй длинну поля products.sku если она не равна 13 символам, то пропускаем итерацию.

Если длина равна 13 символам, то ищем во временной таблице запись с таким же штрихкодом.

Если запись найдена переноси данные из временной таблицы в таблицу product_prices, цену и количество ставим = 0, Далее производим поиск во временной таблице всех элементов у которых поле title = полю title найденной записи, и для каждого найденного элемента создаем новую запись в таблице product_prices.

Если запись не найдена то создаем в таблице product_prices новую запись поля в которой заполняем следующим образом:

- product_id = products.id
- sku = products.sku
- ext_id = null
- category_id = null
- value = "-"
- count = 0
- price = 0
