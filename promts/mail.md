Создай класс для отправки почтового собщения об статусе оплаты и примени его в строке 72 файла app/Services/YooKassaService.php.

Для котправки сосздай простой блейд шаблон в папке resources/views/mail. В не отобрази всю переданную информацию.

Для в класс будут передаваться следующие данные:

- id заказа
- id платежа
- Статус заказа
- Сумма заказа
